# Prosto Apps Catalog

Официальный источник приложений для магазина Prosto Apps. В каталоге доступны локальные «Заметки», «Прогноз Open-Meteo», «Каталог покемонов» и «JSONPlaceholder (демо)». [Каталог JSON на GitHub Pages](https://prostodot.github.io/apps-catalog/catalog.json)

«Прогноз Open-Meteo» получает данные от Open-Meteo. [Некоммерческий API](https://open-meteo.com/en/terms) · [Лицензия данных прогноза CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

«Каталог покемонов» читает список из PokéAPI порциями по 20 записей. [Документация PokéAPI](https://pokeapi.co/v2#resource-lists-pagination-group)

«JSONPlaceholder (демо)» показывает тестовые публикации, комментарии, альбомы и задачи. API имитирует сохранение изменений. [Документация JSONPlaceholder](https://jsonplaceholder.typicode.com/guide/)

## Публикация приложений

Здесь публикуются готовые версии манифестов для установки из магазина. Примеры для разработки и тестов хранятся в Prosto Apps Manifests. [Примеры манифестов](https://github.com/prostodot/apps-plugins/tree/main/examples)

В официальном источнике публикуйте каждую версию под отдельным именем файла и меняйте `version` и `manifest` в `catalog.json` вместе. Приложение скачивается по нажатию «Установить». Установленный экземпляр хранится на устройстве, а новая запись каталога с тем же идентификатором его не заменяет.

## Свой источник

Разместите `catalog.json` и манифесты на любом публичном HTTPS-хостинге. Добавьте прямой адрес `catalog.json` в магазине Prosto Apps. Для Web, PWA и настольного клиента хостинг должен разрешать чтение JSON с адресов клиентов через CORS. Например, можно указать `Access-Control-Allow-Origin: *`. Клиент делает запросы без учётных данных и не следует перенаправлениям.

Используйте [пример каталога](catalog.json) и [JSON Schema](catalog.schema.json). Поле `schemaVersion` равно `1`, а `apps` содержит до 500 записей с уникальными `id`. Поле `version` — версия опубликованного манифеста, отображаемая в магазине. `manifest` — относительный путь к JSON-файлу от каталога. Допустим префикс `./` и параметры запроса после имени файла. В сегментах пути разрешены латинские буквы, цифры, дефис, подчёркивание и точки внутри сегмента. Каталог и каждый манифест могут занимать до 1 МиБ. `id` в записи должен совпадать с `id` в манифесте приложения.
